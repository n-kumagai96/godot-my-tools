# A Collection of Convenient Tools 

To use them, 
- may need to place under the parent folder directly or somewhere else
- may need some modifications

## Details

1. GenerateProjectFiles.bat
    - Something like UnrealEngine's GenerateProjectFiles.bat to generate the Visual Studio solution when needed. 
2. LaunchEditor.bat
    - Open the specified project with the specified engine 
3. GenerateExportTemplate_XXX.bat
    - Generate the export templates for exporting the project.
